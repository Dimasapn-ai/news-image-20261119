A program that draws one newspaper front page summing up the world news of Thursday 19 November 2026: the first Trump-Xi-Putin trilateral summit in Shenzhen and its peace declaration, the ICJ's genocide ruling against Myanmar, the Strait of Hormuz in flames, Ukraine's third strike on the Kerch Bridge, Anthropic's record IPO — plus Van Gogh's record sale, GTA VI's worldwide launch, the Riyadh tower attack and Denmark's Greenland deal in the footer.

`main.py` is pure Python standard library: its own PNG encoder, a hand-authored stroke font, and every illustration drawn in code. It writes `entry.png` (1024x1024) deterministically — same bytes on every run.
